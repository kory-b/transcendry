# Project Context

## Purpose

Transcendry is a static website for a practical transformation advisory business focused on data, AI, automation, analytics, and digital execution.

The current website goal is to establish credibility and convert qualified visitors into conversations.

## Positioning

Primary positioning:

> Practical transformation through data, AI, and digital execution.

Expanded positioning:

> Transcendry helps business teams turn AI ambition, messy data, and manual workflows into clear roadmaps, useful prototypes, and digital products that improve how work gets done.

## Audience

Primary audiences include operations, analytics, supply chain, finance/reporting, digital transformation, IT/data, and mid-market business leaders.

## Brand Voice

Use language that is clear, calm, credible, practical, modern, strategic, and grounded.

Avoid hype-heavy language such as:

- Revolutionary AI
- Exponential disruption
- Autonomous enterprise transformation
- Next-generation AI-powered everything

Prefer language such as:

- Practical AI
- Data products
- Workflow transformation
- Decision speed
- Operational clarity
- Roadmaps and prototypes
- Useful systems
- Measurable business value

## Current Technical Shape

- Static HTML/CSS website.
- Production files live in `public/`.
- Local server uses Python's built-in HTTP server on port `4173`.
- Deployment target is Cloudflare Pages.
- Build output directory is `public`.
- No JavaScript framework, package manager, build pipeline, or analytics stack is currently required.
